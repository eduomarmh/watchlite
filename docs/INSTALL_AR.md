# تثبيت WatchLite على الساعة

## 1. فتح وضع المطوّر
1. الإعدادات ← **حول الساعة** (About / System / Version حسب الساعة).
2. اضغط على **Build number** (رقم الإصدار) **7 مرات** لحد ما تظهر رسالة "أنت الآن مطوّر".
3. ارجع للإعدادات، هتلاقي **Developer options** (خيارات المطوّر).
4. فعّل **USB debugging**.

## 2. التثبيت
- **أسهل طريقة:** انقل ملف `app-release.apk` للساعة (بلوتوث أو كابل أو أي تطبيق نقل)، وافتحه من مدير الملفات. لو طلب "السماح بالتثبيت من مصادر غير معروفة" اسمح.
- **بالـ ADB (لو الكابل بينقل بيانات):** `adb install -r app-release.apk`
- **ADB بالواي فاي:** لو الكابل شحن بس، دوّر في خيارات المطوّر على **Wireless debugging** أو **ADB over network**، وبعدين: `adb connect IP_الساعة:5555`

## 3. خليه اللانشر الأساسي
اضغط زرار **الهوم** ← اختار **WatchLite** ← **دائمًا**.

## 4. الصلاحيات (كلها اختيارية)
افتح **إعدادات الساعة** من قائمة التطبيقات ← **الصلاحيات**:
| الصلاحية | لزمتها |
|---|---|
| صلاحية الإشعارات | عرض الإشعارات والرد عليها |
| قفل الشاشة | زرار الهوم يقفل الشاشة على طول |
| قائمة الطاقة (إمكانية الوصول) | فتح قائمة الإيقاف والتطبيقات الأخيرة من مركز التحكم |
| عدم الإزعاج | زرار عدم الإزعاج في مركز التحكم |
| تعديل إعدادات النظام | زرار الإضاءة في مركز التحكم |
| الموقع | مواقيت الصلاة بموقعك الحقيقي، وربط البلوتوث |

## 5. لو العجلة مش شغالة
الإعدادات ← الإيماءات والأزرار ← **اختبار الأزرار والعجلة**. لف العجلة وشوف بيظهر إيه. لو مفيش حاجة بتحصل في اللانشر، اضغط "تعليم لفوق" ولف لفوق، وبعدين "تعليم لتحت" ولف لتحت.

## 6. الرجوع للانشر الأصلي
إعدادات الساعة ← الصلاحيات ← **تطبيق الشاشة الرئيسية**، واختار اللانشر القديم.
ولو اللانشر وقف كذا مرة ورا بعض، هيفتح **الوضع الآمن** تلقائي، وفيه زرار للرجوع.
